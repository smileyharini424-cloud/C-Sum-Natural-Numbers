# C Sum of Natural Numbers

## Explanation

This program calculates the sum of the first N natural numbers.

The user enters a positive integer N and the program adds all numbers from 1 to N.

## Problem Statement

Write a C program to find the sum of the first N natural numbers using a loop.

## Features

- Accepts a positive integer
- Calculates the sum of natural numbers
- Uses a for loop
- Uses an accumulator variable
- Handles invalid input

## How It Works

The program accepts a positive integer N.

A variable named sum is initialized to zero.

A for loop starts from 1 and continues up to N.

During every iteration the current value of i is added to sum.

After the loop finishes the total sum is displayed.

## Sample Input

Enter a positive integer: 10

## Sample Output

Sum of first 10 natural numbers = 55
